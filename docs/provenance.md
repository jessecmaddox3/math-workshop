# Source and asset provenance

> **TL;DR:** The two complete games were extracted from this author’s personal website into fresh history. Original personal hubs, account configuration, learner state, analytics and website history were excluded. The default learner and all tests are invented.

The owned source comprises Target Number’s controller and exact rational solver, Area Mazes’ controller and all17 authored puzzles, and their shared paper/teal stylesheet. Original architectural choices are described in [design](design.md). No game from another person’s supplied project was included.

The optional save/cloud engine is reused from this author’s MIT-licensed [Colors v1.0.0](https://github.com/jessecmaddox3/color-learning/releases/tag/v1.0.0), commit `1030a1e54b0ca6e5de1172148d7d55e1a4d74a42`. Math integration uses separate game databases, versioned snapshots and parameterized panel destinations. The source carries all dependency notices, with pinned versions recorded in `package-lock.json` and `licenses/npm/SOURCES.json`.

The games use system fonts, native controls and CSS, with no external artwork or font requests. The banner in `docs/math-workshop-hero.png` was generated with the built-in ChatGPT image tool for this release. It depicts an invented paper workbench, a correct 2×3×4=24 equation and schematic area shapes. No personal photograph or existing drawing was supplied. The exact prompt is in `hero-prompt.txt`.

Area Mazes acknowledges inspiration from Naoki Inaba’s Menseki Meiro, separately from the license on these authored puzzles. No outside puzzle feed or tutorial images are redistributed. MIT covers the app’s owned code and assets; dependency notices retain their respective terms.
