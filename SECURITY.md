# Reporting a security or privacy issue

Use [GitHub private vulnerability reporting](https://github.com/jessecmaddox3/math-workshop/security/advisories/new). Do not put private learner exports, tokens, email addresses or backend credentials in a public issue.

Default play makes no external requests. Optional cloud is an adult opt-in to a host-owned service. Configure a new backend with the supplied owner-bound schema; never remove RLS or put a service-role/secret key in browser code. Local browser storage and JSON exports are readable by anyone with access to them.
