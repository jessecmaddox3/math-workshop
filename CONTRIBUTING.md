# Make it your own

This started as a personal project. Fork it, change it, and send a pull request if an improvement could help other people too. MIT permits private and commercial reuse with its notice retained.

Good contributions include independently authored and mathematically verified area puzzles, clearer nontechnical setup, better keyboard/touch behavior, and documented testing on actual phones. Preserve exact fractions, visible working, optional second routes and the deliberately unscaled diagrams.

Run the existing Node and browser tests for behavior changes. Add a small regression for a reproduced bug. Use fictional learners and progress; never attach actual children’s names, exports, account addresses or backend credentials to an issue. Keep generated `app.js` files and offline artifacts reproducible with `npm run build`. Do not include `node_modules`, local cloud configuration or personal data in commits.
